# seni-cloud-sandbox

Repositorio aislado para colaboración con agentes cloud sobre artefactos públicos/docentes (sin acceso a código propietario, telemetría privada ni documentación de patente).

## Estructura
- `presentaciones_oficiales/seni_ia/v_docente/`: Portal de presentación institucional UPV (100% offline), compuertas (`GATES.md`), verificadores y propuestas de elevación (`propuestas_elevacion/`).
